Política de privacidade: Painel réplica

Atualizada em 10 de outubro de 2026.

O que é

O Painel réplica é um aplicativo de uso pessoal. Ele roda só no computador do próprio usuário e não tem servidor na internet.

Que dados do Google ele acessa

Dois escopos, cada um com autorização própria:

  • calendar.app.created: criar uma agenda secundária e ver, criar, alterar e excluir os eventos dessa agenda;
  • gmail.send: só enviar mensagens a partir da conta do usuário, e só para o próprio endereço do usuário.

O aplicativo não lê as outras agendas, os contatos, a caixa de e-mail, os rascunhos nem os arquivos do usuário.

Como os dados são usados

A agenda serve só para manter "Prazos (réplica)" igual aos prazos que o usuário registra no aplicativo e para perceber as mudanças feitas nela. O envio de e-mail serve só para mandar ao próprio usuário o resumo dos prazos nos dias úteis e avisos de falha do aplicativo.

O que o e-mail contém

Texto simples, sem links, imagens nem rastreamento: a data, contagens e, para cada item, o código, o tipo, a prioridade, o prazo, o código do responsável, a situação e uma próxima ação padronizada. Só nos itens criados no próprio aplicativo vai também o título escrito pelo usuário, abreviado; os demais aparecem só pelo código. O aplicativo não guarda cópia do texto enviado. A mensagem fica na conta de e-mail do próprio usuário (Caixa de entrada e Enviados), que pode apagá-la.

Avisos no celular

O aviso no celular é enviado pelo serviço de notificações do navegador Chrome (Google), sem conteúdo: o serviço só fica sabendo que houve um aviso, quando e para qual aparelho. Os números aparecem porque o celular os busca diretamente no computador do usuário, pela rede privada dele.

Onde ficam e com quem são compartilhados

Os dados do aplicativo ficam só no computador do usuário; a agenda criada e os e-mails enviados ficam na própria conta Google do usuário. As autorizações de acesso são guardadas no Gerenciador de Credenciais do Windows. Nada é vendido, transferido ou compartilhado com terceiros, e nada é usado para publicidade ou para treinar modelos de inteligência artificial.

O uso das informações recebidas das APIs do Google segue a Política de Dados do Usuário dos Serviços de API do Google, inclusive os requisitos de Uso Limitado.

Como revogar o acesso

A qualquer momento, em myaccount.google.com/connections, o que remove de uma vez o acesso à agenda e o envio de e-mail. Pelo próprio aplicativo, o usuário pode parar só o envio de e-mail, apagando do computador a autorização correspondente, ou revogar tudo. A agenda criada e os e-mails já enviados continuam na conta do usuário, que pode excluí-los quando quiser.
