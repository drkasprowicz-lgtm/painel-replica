Política de privacidade: Painel réplica

Atualizada em 6 de outubro de 2026.

O que é

O Painel réplica é um aplicativo de uso pessoal. Ele roda só no computador do próprio usuário e não tem servidor na internet.

Que dados do Google ele acessa

Só o escopo calendar.app.created: criar uma agenda secundária e ver, criar, alterar e excluir os eventos dessa agenda. O aplicativo não lê as outras agendas, os contatos, os e-mails nem os arquivos do usuário.

Como os dados são usados

Os dados servem só para manter a agenda "Prazos (réplica)" igual aos prazos que o usuário registra no aplicativo, e para perceber as mudanças feitas nela.

Onde ficam e com quem são compartilhados

Ficam só no computador do usuário. O token de acesso é guardado no Gerenciador de Credenciais do Windows. Nada é vendido, transferido ou compartilhado com terceiros, e nada é usado para publicidade ou para treinar modelos de inteligência artificial.

O uso das informações recebidas das APIs do Google segue a Política de Dados do Usuário dos Serviços de API do Google, inclusive os requisitos de Uso Limitado.

Como revogar o acesso

A qualquer momento, em myaccount.google.com/connections, ou pelo próprio aplicativo. A agenda criada continua na conta do usuário, e ele pode excluí-la quando quiser.

Contato

Pelo e-mail de suporte exibido na tela de consentimento do Google.
